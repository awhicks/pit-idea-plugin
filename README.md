# Web-CAT Mutation Testing

![build](https://github.com/awhicks/pit-idea-plugin/actions/workflows/build-gradle-project.yml/badge.svg?branch=master)

IntelliJ IDEA plugin for running [PIT mutation testing](http://pitest.org) inside the IDE.

After a run, lines needing better testing are marked directly in the editor (hover the gutter
icon for mutation descriptions), and actionable mutants are listed in the "Mutation List" tool
window with click-to-navigate.

Forked from the MIT-licensed [pit-idea-plugin](https://github.com/mjedynak/pit-idea-plugin) by
Michal Jedynak.
